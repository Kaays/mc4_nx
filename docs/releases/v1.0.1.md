# mc4_nx v1.0.1

Fix for the quick-time events.

## Fixed

- **The bars filled with a finger** (for example when an enemy grabs you in a cutscene) could not be filled:
  1.0.0 held back the touch screen during cutscenes so that only + skips them. During a quick-time event the touch
  screen now works again. The right stick also works as the finger (flick it the way you would swipe, again and
  again), for docked play.

## Update

Replace `sdmc:/switch/mc4_nx/mc4_nx.nro` with the new one and start the game from the same HOME-menu icon. Saves and
settings stay. First install: see the [README](https://github.com/Kaays/mc4_nx#install).

## Known issues

- No multiplayer or online features (Gameloft's servers are gone).
