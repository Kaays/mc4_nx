# mc4_nx v1.0.0

First public release: Modern Combat 4: Zero Hour, the 32-bit Android release 1.2.3e, running natively on the
Nintendo Switch. Playable: campaign, menus, sound, the Gameloft logo, briefing videos and cutscenes, saves, the
game's languages (Turkish included), 60 FPS, 720p handheld / 1080p docked.

**Needs your own copy of the game**: the Android APK of 1.2.3e and its two OBB files. No game files are included.

## Files

- `mc4_nx.nro`: the port (the 32-bit game program rides inside it)
- `SHA256SUMS`

## Install

You need Atmosphère and [sphaira](https://github.com/ITotalJustice/sphaira).

```text
sdmc:/switch/mc4_nx/
├── mc4_nx.nro
├── mc4.apk          (your APK, any name)
└── obb/
    ├── main.1100.com.gameloft.android.ANMP.GloftM4HM.obb
    └── patch.12222.com.gameloft.android.ANMP.GloftM4HM.obb
```

1. Copy the files as above (do not extract the OBBs).
2. sphaira: **Homebrew → Modern Combat 4 → Install Forwarder**.
3. Start the game from its **HOME-menu icon** (not from the homebrew menu). The first start sets itself up with a
   progress bar; later starts go straight to the game.

Keep `data/gluid.bin` in the game folder: the saves are tied to it.

Details, controls and settings: [README](https://github.com/Kaays/mc4_nx#install).
